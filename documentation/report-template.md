# Report Template Specification & Formatting Guide

Detailed Event Report template specification, including typography, font sizes, photo captions, and dynamic fields.

---

## 1. Typography & Formatting Rules

| Section | Font Family | Font Size | Style | Alignment |
| :--- | :--- | :--- | :--- | :--- |
| **Document Headers / Titles** | Times New Roman / Calibri | **14 pt** | Bold | Left |
| **Metadata Labels** *(Event, Date, etc.)* | Times New Roman / Calibri | **12 pt** | Bold | Left |
| **Metadata Values** | Times New Roman / Calibri | **12 pt** | Regular | Left |
| **Section Headings** *(Introduction, etc.)*| Times New Roman / Calibri | **13 pt** | Bold | Left |
| **Body Paragraphs** *(Intro, Discussion)* | Times New Roman / Calibri | **12 pt** | Regular | Justified (1.15 line spacing) |
| **Photo Captions** | Times New Roman / Calibri | **10.5 pt** | Italic / Regular | Centered below each image |
| **Signatures** | Times New Roman / Calibri | **12 pt** | Bold | Left & Right Columns |

## 3. Dynamic Fields & Minor Details

### A. Core Narrative (AI Generated)
- `introduction`: Opening event context and objectives *(12 pt, Regular)*.
- `discussion`: In-depth breakdown of workshop topics, AI tools, and workflows *(12 pt, Regular)*.
- `conclusion`: Key learner takeaways and closing results *(12 pt, Regular)*.

### B. Event Metadata
- `event_title`: Name of the event *(14 pt, Bold)*.
- `event_date`: Date conducted *(12 pt, Regular)*.
- `participant_count`: Number of attendees *(12 pt, Regular)*.
- `department`: Department name *(Default: "All")*.
- `target_audience`: Audience target *(Default: "AIML Club learners")*.
- `speakers`: List of speakers & designations *(12 pt, Bulleted / Regular)*.

### C. Photo Captions (Minor Details - Customizable)
- `photo_1_caption`: *"Speakers introducing the concepts of AI&ML to the learners"*
- `photo_2_caption`: *"Students engaging in the session"*
- `photo_3_caption`: *"Speaker solving doubts of students"*
- `photo_4_caption`: *"Winner of Mentimeter quiz competition"*
*(All captions styled at 10.5 pt, centered below images).*
